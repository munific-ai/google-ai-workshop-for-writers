Google Cloud AI workshop for writers
===

記者向けの Gemini / Google Workspace with Gemini / Gemini Enterprise ハンズオン。
**60 分（20 分 × 3 パート）** で、個人の生産性向上と組織の業務効率化の違いが体験できます。

---

## コンセプト

AI に任せるのは、取材の準備・下調べ・図表づくり・事実確認・表記統一といった**周辺業務**に絞りました。中核の執筆は人が担い、周辺をエージェントが引き受ける —— この構図はそのまま一般企業の読者にも置き換わります。

## 全体の骨格

**Part 2 と Part 3 で「仕事の種類」を変え、その違いを体感いただきます。**

|                    | Part 2                             | Part 3                                 |
| ------------------ | ---------------------------------- | -------------------------------------- |
| 何をするか         | **手元のデータを、自分で加工する** | **散らばった情報を、探さずに横断する** |
| ファイルを開くのは | **参加者**                         | **誰も開かない**                       |
| 成果物             | 自分のための図表                   | **他人も使えるエージェント**           |
| 対応する価値       | 個人の生産性向上                   | 組織の業務効率化                       |

| Part | 製品                  | いなくてもできるようになる専門職                       |
| ---- | --------------------- | ------------------------------------------------------ |
| 1    | Gemini                | **ML エンジニア**（表データが予測に使える）            |
| 2    | Workspace with Gemini | **データアナリスト**（手元のデータが図表になる）       |
| 3    | Gemini Enterprise     | **校閲者・情報システム部門**（社内の知識が引き出せる） |

### 縦串：Part 1 の下調べが、Part 3 の取材質問になる

Part 1 で読む [TabFM の記事](https://research.google/blog/introducing-tabfm-a-zero-shot-foundation-model-for-tabular-data/) には、**`AI.PREDICT` で BigQuery に統合予定**と書かれています。
そして明日の取材相手は、その BigQuery を擁する **Google Cloud のデータ分析部門 VP** です。

**下調べ → 取材準備 → 質問**が一直線につながります。

### 2 つの山場

**Part 2 — グラフが作れずに詰まる瞬間**

3 社の「全社展開までの期間」は「約 6 週間」「約 2 か月」「PoC 継続中」。**単位が揃っていません。**

参加者が書いている記事の主題は「京浜運輸は指標の定義が揃っていなくて 2 か月かかった」でした。
そして**グラフを作ろうとした瞬間に、まったく同じ問題に直面します。**

**Part 3 — 3 年前の自社の失敗**

> **「なお貴媒体は 2023 年 10 月にも、同じ役職名で訂正を掲載しています（COR-2023-0147）」**

この訂正記録は **Google Chat にしか存在しません**。Docs のサイドパネルから Chat を `@` で指定することはできないため、**Part 2 のやり方では構造的に届かなかった**情報です。

自社の失敗なので、特定製品を批判せずにシステム横断の価値を伝えられます。

## ⚠️ 実在企業の扱い

| 対象                                                                | 扱い                                                                                                      |
| ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **SOLVRA株式会社／静和精機／京浜運輸／東雲デジタル銀行／TECHSCOPE** | **すべて架空**。人物・数値・発言も架空。**仕込みの誤りはすべてここに寄せてある**                          |
| **Google Cloud**                                                    | **実在**。VP の氏名は設定せず、**取材は物語上「明日」＝未実施**。発言・価格・実績はデータに一切登場しない |
| **Part 1 で読むブログ記事**                                         | **実在**する公開情報                                                                                      |

データは**すべて架空企業に閉じています**。「本物に見える偽の取材記録」を作らずに、ワークショップの仕掛けは完全に成立します。

**冒頭スライドでこの点を必ず明示してください。** 記者が参加するため、この一言の有無が信頼に直結します。

すべての架空社名は、実在企業との衝突がないことを検索で確認済みです。
