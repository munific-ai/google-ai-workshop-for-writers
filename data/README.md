接続するのは **Google Drive / Google Chat / Gmail の 3 つだけ**です。

> ⚠️ **20 名運用の前提**

> 各システムへ投入する前に**必ず削除してください。**

## 設計上いちばん重要な一点

**訂正記録 COR-2023-0147 は、Google Chat の `校閲・訂正` スペースにしか存在しません。**

Google ドキュメントのサイドパネルから Chat を `@` で参照することはできないため、
**Part 2 のやり方では構造的に到達できず、Part 3 でのみ発見される**という設計です。

これがワークショップ最大の山場を支えています。ここだけは崩さないでください。

## 原稿に仕込んだ「編集方針違反」（3 か所）

**事実としては正しいが、編集方針に反する記述**です。
根拠は `編集ハンドブック/editorial-brief-2026-08`（特集の編集方針）。

| #   | 原稿の記述                                        | 分類                 | 方針のどこに反するか                 |
| --- | ------------------------------------------------- | -------------------- | ------------------------------------ |
| A   | 「AI エージェントは事務職の仕事を代替しつつある」 | **炎上リスク**       | 雇用への断定。取材で言われていない   |
| B   | 「もっとも遅れているのが京浜運輸である」          | **トーン（序列化）** | 業務特性の違いを優劣として読ませない |
| C   | 「数年内にあらゆる業務が置き換わるだろう」        | **主題からの逸脱**   | 出典のない未来予測。事例記事の主題外 |

エージェントはこれらを **【方針】** として分類し、事実の誤りより**上に**置くのが期待動作です。

さらに **読者ペルソナを経営層に差し替えて再実行**すると、
**同じ原稿・同じ事実でも指摘の優先順位が変わります。**
