## ★ このシートを見てわかること

### 1. 効果の幅が、けた違いに大きい

| 企業                       | 削減率・改善幅       |
| -------------------------- | -------------------- |
| テレビ朝日                 | 約 99.5%             |
| イオンリテール             | 90%                  |
| 東京電力エナジーパートナー | 約 60%               |
| グリーホールディングス     | 16%                  |

**同じ「AI エージェント導入」でも、削減率は 99.5% から 16% まで開いている。**

> ⚠️ **「200 倍速」と「16% 減」を並べて書かないこと。**
> 倍率と削減率は次元が違います。並べるなら**削減率に統一**してください。

### 2. 効果の測り方が、企業ごとにバラバラ

時間 / 人時・年 / か月 / パーセント / 精度 —— **単位が揃っていない。**
そのまま並べても比較にならない。**削減率に換算して初めて横に並ぶ。**

### 3. 効果が大きいのは、判定基準が明確な業務

| 業務                     | 判定基準           | 効果 |
| ------------------------ | ------------------ | ---- |
| ファクトチェック         | 事実か否か。明確   | 最大 |
| 商品情報の登録           | 登録ルールがある   | 大   |
| データ分析               | 手順を分解できる   | 中   |
| 社内問い合わせ           | 例外処理が多い     | 小   |

→ **取材した 5 社の話と、きれいに一致する。**
