# 【プレスリリース】データ基盤導入支援サービス「Solvra DWH Migration」を「Solvra Data Bridge」へ名称変更

**SOLVRA株式会社**
2025年4月1日

---

SOLVRA株式会社（本社：東京都渋谷区、代表取締役 CEO：五十嵐 遼）は、2025年4月1日をもって、データ基盤導入支援サービス **「Solvra DWH Migration」の名称を「Solvra Data Bridge」へ変更**したことをお知らせします。

## 名称変更の背景

「Solvra DWH Migration」は 2021年6月の提供開始以来、既存データウェアハウスからの移行支援サービスとしてご利用いただいてまいりました。

このたび、移行そのものにとどまらず、**権限設計・データガバナンスの整備・指標定義の棚卸し**を含めた基盤づくり全体を支援する位置づけへと拡張するにあたり、名称を **「Solvra Data Bridge」** へ変更いたします。

## 変更内容

| 項目       | 変更前               | 変更後                 |
| ---------- | -------------------- | ---------------------- |
| サービス名 | Solvra DWH Migration | **Solvra Data Bridge** |
| 適用日     | —                    | 2025年4月1日           |

- 既存のご契約はそのまま継続されます

## 報道関係者の皆さまへのお願い

2025年4月1日以降の記事におきましては、**「Solvra Data Bridge」**の表記をご使用くださいますようお願いいたします。

英字表記は **Solvra Data Bridge**（各単語の頭を大文字、間は半角スペース）です。
