# TECHSCOPE 編集ハンドブック｜用字用語ガイド

**版数**：第 7 版
**改訂日**：2026年4月1日
**管理**：編集部 デスク（三村）

本ガイドは TECHSCOPE に掲載するすべての記事に適用されます。
判断に迷う場合はデスクに確認してください。

---　

## 1. 外来語の長音（もっとも指摘が多い項目）

**原則：長音符号「ー」を付ける。**

| ✕ 使わない     | ○ 使う               |
| -------------- | -------------------- |
| ユーザ         | **ユーザー**         |
| サーバ         | **サーバー**         |
| コンピュータ   | **コンピューター**   |
| ブラウザ       | **ブラウザー**       |
| プロバイダ     | **プロバイダー**     |
| インタフェース | **インターフェース** |

> 例外：製品名・社名として長音なしが正式表記の場合は、正式表記を優先します。

## 2. 送り仮名

| ✕ 使わない       | ○ 使う                       |
| ---------------- | ---------------------------- |
| **行なう**       | **行う**                     |
| 表わす           | 表す                         |
| 現われる         | 現れる                       |

## 3. AI 関連用語の表記（2026年4月 新設）

生成 AI の普及に伴い、以下を統一表記とします。

| 用語             | 正しい表記                                    | 備考                                                   |
| ---------------- | --------------------------------------------- | ------------------------------------------------------ |
| AI エージェント  | **AI エージェント**                           | **「AI」と「エージェント」の間に半角スペース**を入れる |
| 生成 AI          | **生成 AI**                                   | 同上                                                   |
| AI アシスタント  | **AI アシスタント**                           | 同上                                                   |
| 大規模言語モデル | **大規模言語モデル**（初出）／以降 **LLM** 可 |                                                        |
| 基盤モデル       | **基盤モデル**                                | foundation model の訳語はこれで統一                    |

⚠ **「AIエージェント」（スペースなし）、「ＡＩエージェント」（全角）はいずれも誤りです。**
一つの記事の中で表記が混在するケースが多発しています。入稿前に必ず一括検索してください。

---

## 4. 企業名・製品名

- **正式名称を使う。** 前株・後株を必ず確認すること
- 初出は正式名称、2 回目以降は略称可（略称を使う旨を初出時に明示）
- **役職名は取材時点の名刺および会社概要で確認する**
- 「株式会社」の位置を誤ると訂正対象になります（→ §6）

---

## 5. 数値・時期

- 数値は**一次資料で裏を取る**。広報の口頭説明のみを根拠にしない
- 決算数値は**決算短信または決算説明資料**を出典とする
- 「約」を付ける場合も、根拠となる正確な数値を把握したうえで判断する
- **Preview（限定提供・ベータ）と一般提供（GA）を区別する。**
  「提供開始」とだけ書かない。どちらかを明記すること

---

## 6. 訂正を出した事例からの注意（再発防止）

過去に訂正を掲載した事案のうち、再発しやすい類型を挙げます。

| 類型                           | 教訓                                                        |
| ------------------------------ | ----------------------------------------------------------- |
| 取材先役員の**役職**を誤記     | **「取締役」と「執行役員」は別物。** 会社概要で必ず確認する |
| 価格の**月額・年額**を取り違え | 単価表記の単位を必ず確認する                                |
| **旧サービス名**のまま掲載     | 改称の有無をサービスページで確認する                        |
| **プレビュー**を一般提供と誤記 | 提供状況を発表資料で確認する                                |

> **訂正番号つきの個別記録は、Google Chat の「校閲・訂正」スペースにあります。**
> 誰が・いつ・なぜ間違えたのか、再発防止策まで含めて記録してあります。
> **入稿前に、取材先名でこのスペースを検索してください。**
> 同じ取材先で同じ誤りを繰り返している事例が実際にあります。

---

## 7. 引用

- **発言者を特定できる形で書く。** 「関係者」「担当者」は原則使わない
- やむを得ず匿名にする場合は、所属・役職の範囲で特定できるところまで書く
- 取材メモで発言者が特定できる発言を「関係者」と書かない

---

## 8. 断定の程度

出典が述べている範囲を超えて断定しないこと。

| 出典の表現             | ✕ 書いてはいけない             | ○ 書いてよい                             |
| ---------------------- | ------------------------------ | ---------------------------------------- |
| 「採用が広がっている」 | 業界標準になった／事実上の標準 | 採用が広がっている／採用が広がりつつある |
| 「検討している」       | 導入を決めた                   | 導入を検討している                       |
| 「〜と考えられる」     | 〜である                       | 〜とみられる                             |
| 「提供を予定している」 | 提供が始まった                 | 提供が予定されている                     |

### 実在する製品・サービスについて（特に注意）

**シェアや優劣に関する断定は、必ず出典を示せる範囲にとどめてください。**

- 「事実上の標準」「デファクトスタンダード」「最も使われている」といった表現は、
  **調査会社のレポートなど、出典を示せる場合を除いて使わない**
- 取材先が「採用が広がっている」と述べたことを根拠に、
  「標準になった」と書くことはできません
- 比較記事以外で、特定製品を他製品より優れていると読める書き方をしない

> 過去に訂正には至らなかったものの、取材先から表現の修正を求められた事例が複数あります。
