## 1. 物語の骨格

### 通し軸：専門職がいなくても、仕事が前に進む

| Part | 体験                                     | いなくてもできるようになる専門職                       |
| ---- | ---------------------------------------- | ------------------------------------------------------ |
| 1    | AI エージェントの記事を読み解く          | **英語と技術の通訳**（海外の一次情報が読める）         |
| 2    | 取材メモを表とグラフにする               | **データアナリスト**（手元のデータが図表になる）       |
| 3    | 組織のデータを横断し、エージェントを作る | **校閲者・情報システム部門**（社内の知識が引き出せる） |

### Part 2 と Part 3 の違い（この構成の要）

**タスクの種類そのものが違います。** 「見える範囲の差」ではありません。

|              | Part 2                             | Part 3                                 |
| ------------ | ---------------------------------- | -------------------------------------- |
| 何をするか   | **手元のデータを、自分で加工する** | **散らばった情報を、探さずに横断する** |
| 対象         | 自分が開いた 5 つの取材メモ        | 共有ドライブ全体・Chat・Gmail          |
| 成果物       | 自分のための図表                   | **他人も使えるエージェント**           |
| 対応する価値 | 個人の生産性向上                   | 組織の業務効率化                       |

Part 3 の冒頭で必ずこう繋ぎます。

> 「Part 2 では、**自分でファイルを開いて、自分で表を作りました**。今度は、開かずにやってみましょう。」

### Part 1 と Part 3 の接続

Part 1 で読む記事には、AI の使われ方が **3 段階**で示されています。

```
チャットボット  →  単一エージェント  →  マルチエージェント
（質問に答える）    （業務を実行する）    （複数が連携する）
```

Part 3 で、この段階を踏まえて VP への質問を組み立てます。

> 「日本企業の多くは、まだ第 1 ~ 2 段階に見える。マルチエージェントの話は早いのではないか」

→ 横断検索で **公開事例まとめ** に到達
→ 東京電力エナジーパートナーの**マルチエージェント V-DAG が既に稼働している**事実に当たる
→ 質問が更新される

**下調べ → 横断 → 裏取り → 質問**が一直線につながります。

- **作る**：説明図、比較表とグラフ、出典付きの取材ブリーフ、原稿レビューエージェント
- **作らない**：記事本文

## 7. トーンのガードレール

**やること**

- 事実の確認（数値・単位・名称・時期・役職）
- **実在企業の公開事例を、出典付きで正確に引く**
- 効果の差を、業務特性の違いとして構造的に説明する
- AI の指摘を記者が採否判断する

**やらないこと**

- AI に「矛盾を探して」「粗を探して」と指示するプロンプトを例示すること
- **効果が小さい企業を「遅れている」と描くこと**（例外処理の多い業務は定型化されていないだけ）
- 雇用への影響を、取材で得た範囲を超えて断定すること
- **実在企業について、公表されていないことを書くこと**

**プロンプトの言い換え例**

| ✕ 使わない           | ○ 使う                                       |
| -------------------- | -------------------------------------------- |
| 矛盾点を探して       | 数値と**単位**が資料と一致しているか確認して |
| 問題点を挙げて       | 確認が必要な**論点**を出典付きで挙げて       |
| どこが一番遅れている | 効果の差を生んでいる**業務特性**を整理して   |
